# 关联 Prefab、嵌套和变体

编辑模式从 Project 拖入 `.tcprefab` 时，实例根保存 `PrefabLink`，包括模板 Handle、LocalID/场景 UUID 映射和上一次模板基线。场景仍保存完整实体内容。运行时 C# `Instantiate` 继续使用快照创建和延迟脚本初始化，不在游戏运行中自动修改已有实例。

## 编辑工作流

在 Hierarchy 中选择实例根，右键使用：

- **Update Prefab (Keep Overrides)**：更新未修改的字段，保留实例修改。已有实体 UUID 和脚本 AttachmentID 保持不变。
- **Show Prefab Overrides in Console**：列出属性差异、增加/删除的实体；场景放置数据不作为内容覆盖列出。
- **Revert All Prefab Overrides**：恢复最新模板内容，移除实例新增的子树并恢复删除的模板节点；根的 Transform 和外部父级继续保留为关卡放置数据。若删除导致场景校验失败（例如外部关节仍引用该节点），保留整个原场景并报告错误。
- **Apply All Overrides to Prefab**：把实例内容写回模板，保留模板原来的根 Transform；同一关卡里的其他关联实例同步更新并保留自己的覆盖。
- **Unpack Prefab**：解除这一层关联，保留实体内容。

资源导入发布后，编辑器在不处于编辑事务的更新点刷新关联实例。打开其他关卡时刷新该关卡的实例；Cook 同样解析最新模板，所以不必先逐个打开、保存所有关卡。自动刷新产生可撤销的场景记录，不自动保存关卡文件。

更新使用旧模板基线、当前实例和新模板进行三方合并。模板删除了一个已被实例修改的字段、组件或实体时，操作报告冲突并保留原场景。先检查 Console，再决定 Revert 或保留为普通实体。不能通过重新编号 LocalID 来表示同一个模板节点。

Apply 先在临时场景验证结果和其他实例，并检查新增嵌套引用是否导致直接或间接循环依赖，成功后原子替换模板文件。编辑器 Undo/Redo 同时恢复该次 Apply 的模板文件与场景；如果模板已被其他操作改写，则拒绝覆盖文件并报告冲突。这个跨文件历史仅存在于当前编辑器场景会话中，不写入恢复存档。

## 嵌套与变体

把关联实例放在普通父实体下面，再从父实体创建 Prefab，即可保留子模板关联。外层保存自身的实体快照和子模板的覆盖；加载和 Cook 时递归解析子模板。

选择已关联的实例根，菜单显示 **Create Prefab Variant From Selection**。新文件保留对原模板的关联，并将当前修改作为差异。基础模板后续的未覆盖字段变化会传入变体；从变体实例 Apply 仍保留基础模板关联。

复制关联实例会重映射实体、脚本附件和关联基线，不会让副本更新写入原实例。组合加载拒绝循环依赖，深度上限为 32，并在错误中列出依赖链。新增嵌套节点和脚本附件使用稳定的组合身份；碰撞时拒绝操作。

## 数据范围

关联数据通过现有 Scene 11 的组件注册格式保存，Prefab 文档仍为 schema 1。组件和脚本字段的稳定身份用于合并；无稳定元素身份的数组、向量作为整体覆盖。当前菜单提供整实例 Apply/Revert，尚无逐字段勾选的覆盖面板。

测试位于 `Tests/PhysicsRegression/src/PrefabRegression.h`，覆盖两个实例的覆盖隔离、保存重载、位置保持、新增实体 Apply、外部模板刷新、复制后的引用隔离、嵌套继承、变体覆盖和循环拒绝。图形交互与跨文件 Undo/Redo 还需结合真实项目操作验收。
