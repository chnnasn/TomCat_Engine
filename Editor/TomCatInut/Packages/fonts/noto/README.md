The engine registers this file as the built-in font "Noto Sans SC (CJK Fallback)".
Select it as a TextRenderer or UIText Fallback Font to render Simplified Chinese,
Japanese kana and other CJK text. Like every built-in asset, it ships in a cooked
package only when a scene references it, which adds about 8 MB.
